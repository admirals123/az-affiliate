# 🛍 DealHunt — Amazon Affiliate Deal Site

A full-stack deal aggregator that automatically fetches discounted Amazon products
and displays them in a sleek storefront. Powered by the Amazon PA API 5.0.

---

## Project Structure

```
dealhunt-bot/
├── bot/
│   └── fetchDeals.js      ← The deal-hunting bot
├── server/
│   └── index.js           ← Express API (serves deals to frontend)
├── frontend/
│   └── src/App.jsx        ← React storefront
├── data/
│   └── deals.json         ← Auto-generated by the bot (gitignore this)
├── .env.example           ← Copy to .env and fill in your keys
└── package.json
```

---

## Step 1 — Get your Amazon Associates account

1. Go to https://affiliate-program.amazon.com
2. Sign up with your website URL
3. Amazon will review your site (takes a few days)
4. Once approved: go to **Tools → Product Advertising API**
5. Generate your **Access Key** and **Secret Key**
6. Note your **Partner Tag** (looks like `yourname-20`)

> **Canada note**: Sign up at https://associates.amazon.ca for .ca links

---

## Step 2 — Install & Configure

```bash
# Clone / copy this project, then:
cd dealhunt-bot
npm install

# Copy the env template
cp .env.example .env

# Edit .env and fill in your Amazon credentials
nano .env
```

---

## Step 3 — Run the bot (fetches deals)

```bash
node bot/fetchDeals.js
```

This will:
- Search Amazon across 10 categories
- Filter deals with ≥20% discount
- Save results to `data/deals.json`

> The bot runs once per command. The server will auto-run it every 4 hours.

---

## Step 4 — Start the API server

```bash
npm start
# API running at http://localhost:3001
```

**Endpoints:**
- `GET /api/deals` — all deals (supports `?cat=Electronics&sort=discount&q=sony&prime=true`)
- `GET /api/deals/categories` — list of categories
- `GET /api/deals/:asin` — single deal
- `POST /api/bot/run` — manually trigger the bot (requires `x-bot-secret` header)

---

## Step 5 — Start the React frontend

```bash
cd frontend
npm install
npm run dev
# Site at http://localhost:3000
```

Make sure `VITE_API_URL=http://localhost:3001` is set (or create `frontend/.env`).

## Deployment

### Backend (Railway / Render / Fly.io)
1. Push to GitHub
2. Connect to Railway or Render
3. Set all `.env` variables in the dashboard
4. Deploy — the cron job will run automatically

### Frontend (Vercel / Netlify)
1. Set `VITE_API_URL` to your deployed backend URL
2. `npm run build` → deploy the `dist/` folder

---

## Amazon PA API Notes

- **Rate limit**: 1 request per second — the bot respects this automatically
- **Item count**: max 10 items per API request
- **Requirement**: You need to make 3 qualifying sales within 180 days of signing up to keep API access
- **Terms**: Always show the required affiliate disclosure (already in the site)
- **Images**: Must be fetched from Amazon URLs in real-time (don't cache locally)

---

## Customization

**Change categories** → Edit `CATEGORIES` in `bot/fetchDeals.js`
**Change minimum discount** → Edit `CONFIG.minDiscount` (default: 20%)
**Change refresh frequency** → Edit the cron pattern in `server/index.js` (default: every 4h)
**Change marketplace** → Update `host` and `Marketplace` in `bot/fetchDeals.js` (`.com` for US, `.ca` for Canada, `.co.uk` for UK)
